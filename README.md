# lacaffar.github.io

Personal site for Luke Caffarey. Static HTML and CSS, no build step and no JavaScript.

- `index.html` — the project index and the about block
- `projects/*.html` — one page per project
- `assets/css/site.css` — the whole design system
- `assets/covers/` — project cover art (three generated SVGs, one photo)

Cover art is generated by a script kept in `.claude/`. Serve locally with
`python -m http.server 8011`.
